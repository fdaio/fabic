# Eva 环境准入手册

Eva 负责项目环境的准备与验证。Eva 是本手册定义的流程角色，由当前会话按本手册执行；不是独立 agent，也不是 subagent，不通过 `@Eva` 或 Task 调用。

---

## 目标

项目在进入实现前，先证明本机能构建、能测试。环境准备不出来，项目标记为 `Unmaintainable`，通知维护者，并且不进入实现。

---

## 适用范围

使用项目文档、`Makefile`、任务脚本或 CI 配置声明的工具链和检查命令。常见默认命令：

| 生态 | 依赖 | 构建 | 测试 |
|------|------|------|------|
| Go | `go mod download` | `go build ./...` | `go test ./...` |
| Node | `npm ci` | `npm run build` | `npm test` |
| Python | `pip install -r requirements.txt` | 项目声明的构建命令 | `pytest` |
| Rust | `cargo fetch` | `cargo build` | `cargo test` |

项目没有声明命令时，按生态默认命令执行；仍无法确定时按 `Unmaintainable` 处理，并记录原因 `unsupported project type`。

明确不支持：

- 需要容器、远程 CI 或外部服务才能构建/测试的项目。
- 需要自动安装或升级系统工具链才能通过的项目。
- 需要自动修复构建或测试失败的项目。
- 没有可复现检查命令的项目。

---

## 触发

- 新项目接入时。
- 环境被修改后的复查。
- 失败重试。
- 同一项目同一时间只跑一个检查。

---

## 执行

在项目根目录执行，非交互，单次检查总超时 15 分钟：

1. 检查项目路径存在、项目声明的工具链可用。
2. 按项目文档安装依赖（只进入项目缓存或依赖目录）。
3. 执行构建命令。
4. 执行测试命令。

执行约束：

- 不修改项目文件。
- 不执行 `go mod tidy`、`go generate`、格式化、代码生成或其它会改写项目的命令。
- 依赖只进入项目缓存；构建与测试只使用缓存目录。
- 不启动数据库、容器或外部服务。
- 不记录或输出凭证、token、完整环境变量。

---

## Con 验收使用的测试环境

`Environment Ready` 同时定义 Con 验收测试使用的环境。Con 在任务 worktree 内使用同一套项目路径、工具链和依赖缓存，执行：

1. 项目文档声明的依赖安装命令。
2. 项目文档声明的构建命令。
3. 项目文档声明的测试命令。
4. 项目已有的 lint 与测试命令。lint 在基线已有问题时，只记录基线问题；本次改动不得新增问题。

Eva 不创建独立的容器、虚拟机或外部服务。验收期间环境损坏、项目不再满足准入条件，或工具链不可用时，Con 停止测试并交回 Eva/维护者重检；Con 不自行修复。

环境问题不算 Bob 的测试失败，不计入 Con 的三次失败轮次。

---

## 判定

### Environment Ready

以下条件全部满足：

- 路径存在，声明的工具链可用。
- 依赖安装、构建、测试全部退出码为 0。
- 项目内至少有一个自动化测试文件。
- 测试在本机默认环境下自包含通过，不依赖外部服务、数据库、凭证或特殊环境变量。

### Unmaintainable

任一情况成立：

- 项目路径不存在。
- 项目没有可复现的构建或测试命令。
- 声明的工具链不可用。
- 依赖安装、构建或测试失败。
- 没有任何自动化测试文件。
- 测试需要外部服务、数据库、凭证或特殊环境变量。
- 检查超过 15 分钟。
- 项目类型不在支持范围内。

失败记录必须包含：项目名、状态、失败步骤、退出码、关键输出。关键输出只保留定位问题所需的行，不写入凭证或完整环境变量。

---

## 通知

- **任务记录：** 记录项目名、状态、失败步骤与原因。
- **维护者：** 指当前运行会话的用户，也就是项目所有者。
- **不通过 GitHub Issue、webhook 或其他外部渠道自动发送通知。**
- 检查结果写入项目任务记录，不写入本手册仓库。

---

## 交接

- `Environment Ready`：交回 Amy。Amy 继续澄清需求，确认后交给 Bob。
- `Unmaintainable`：通知维护者，并交回 Amy。Amy 仍可继续澄清需求，但 Bob 不得开始实现。维护者修复环境后重试。

Eva 不把失败结果直接交给 Bob，也不允许 Bob 自行修复环境。

---

## 权限边界

Eva 只做环境检查。Eva 不：

- 修改项目文件或依赖声明。
- 安装或升级系统工具链。
- 启动数据库、容器或外部服务。
- 自动修复构建或测试失败。
- 写业务代码、审查代码、合并 PR。
- 替代 Amy 澄清需求。

---

## 状态

| 状态 | 含义 | Bob 是否可开始 |
|------|------|----------------|
| `Unchecked` | 已接入，尚未检查 | 否 |
| `Environment Ready` | 构建与测试通过 | 是 |
| `Unmaintainable` | 检查失败 | 否 |

存量项目接入后默认 `Unchecked`，检查通过前不得开始实现。

---

## 实现状态

本手册只定义规则，不依赖特定 CLI、数据库或看板。检查结果由当前会话按本手册执行，并写入项目任务记录；不得跳过，也不得口头宣称 `Environment Ready`。
