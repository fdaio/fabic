# Accessibility Statement

## Goal

This repository's documentation is provided as plain Markdown. The goal is for readers using screen readers, keyboard navigation, and plain-text environments to get the full content.

## Current support

- Documents use standard Markdown heading levels, lists, and tables.
- Necessary information does not depend on images.
- Links use readable text, not "click here."
- Commands and code use monospace code blocks.

## Known limitations

- Some English terms have no Chinese counterpart.
- Wide tables require horizontal scrolling on narrow screens.
- The repository provides no audio or video versions.

## Reporting accessibility issues

Open an issue describing the affected file, the assistive technology you use (such as a screen reader), and the problem. The maintainer evaluates it and updates this file.

This file is maintained by the repository maintainer. For the contribution process, see [CONTRIBUTING.en.md](CONTRIBUTING.en.md).
